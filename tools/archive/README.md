# Archived harnesses

One-off measurement and reproduction scripts from the work that produced the
current setup. They are kept because they are what the numbers in `docs/` were
measured with, not because they are needed to play. Most hardcode paths or
coordinates for a particular experiment and will need editing before they run.

`splash-ref.png` (a screenshot of the game's splash screen, used by the older
load timers to recognise which screen was on display) is not committed — it is
game artwork. Regenerate it by capturing the splash if you want to run those.

These scripts hardcode `/Users/beanagrammer/Projects/BFME` and coordinates for a
particular window layout. Fix the paths before running any of them.
